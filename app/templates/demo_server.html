This page runs the real dpdpkit-server app, mounted on this site at {{ server_prefix }}/api, and the frame below is plain HTML with no framework: one <script> tag loads @dpdpkit/embed, and three elements (<dpdp-consent>, <dpdp-preferences>, <dpdp-rights-form>) do the rest. The page's own backend, which could be written in any language, keeps the server's API key and hands each widget a short-lived signed token for the person signed in, through token-url. Pick a fictional person, give or withdraw consent, then open a rights request. Data is kept in a temporary database and resets when the site restarts. 

<script src="https://cdn.jsdelivr.net/npm/@dpdpkit/embed@0.1.0-alpha.2/dist/embed.js"></script>
