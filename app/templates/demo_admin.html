This page runs the dpdpkit-admin dashboard (the GitHub release bundle) on a dpdpkit-fastapi backend that was filled with made-up data when the site started. The request queue holds rights requests at different stages, some close to their deadline and one past it; consent analytics counts grants and withdrawals per purpose; the retention monitor lists erasures coming up in the next week; and the incident register has one breach with its notification clocks running. Assign, respond to or reject a request to see it change. Anyone can open this dashboard because the data is fictional, and everything resets when the site restarts.
